# labs/

Step-by-step, hands-on guides — the detailed version of a chapter's "🛠 Hands-on" section, for Tier 1 and Tier 2 chapters.

One folder per chapter that has hands-on content, e.g. `labs/ch09/`. Referenced from the corresponding chapter in [`handbook/`](../handbook/); not meant to be read on its own — see [`outline.md` §9](../outline.md#9-reading-path).
