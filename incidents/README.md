# incidents/

Production-style incidents for the "🐞 Debug Lab" section of **Tier 1** chapters only — a broken system, real symptoms, and no answer key up front. See [`outline.md` §8](../outline.md#8-break-it--the-incident-principle).

One folder per chapter that has a Debug Lab, e.g. `incidents/ch09/`. Not every chapter gets one — incidents are deliberately not spread across every chapter, to avoid forcing it.
